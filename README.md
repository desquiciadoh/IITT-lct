# Помощник диспетчера выездных инженеров

**ЛЦТ 2026, задача № 3 «Билайн Бизнес».** Веб-прототип распределяет заявки рабочего дня между бригадами
и показывает маршруты на карте. Если днём что-то меняется, он перестраивает план. Для каждой заявки
объясняет, почему её взяла эта бригада или почему она осталась без исполнителя.

## Запуск

Нужен только **Python 3.10 или новее**. Интерфейс уже собран, Node.js не нужен.
При первом запуске скрипт 1–2 минуты скачивает зависимости, поэтому нужен интернет.

### Windows

1. Установите Python с [python.org](https://www.python.org/downloads/). В установщике отметьте
   «Add python.exe to PATH».
2. Скачайте проект: `git clone https://github.com/desquiciadoh/IITT-lct.git` или на GitHub **Code → Download ZIP** (архив распакуйте).
3. В папке проекта дважды щёлкните `run.bat`. Из консоли (cmd или PowerShell):

   ```bat
   .\run.bat
   ```

### Linux и macOS

```bash
git clone https://github.com/desquiciadoh/IITT-lct.git
cd IITT-lct
./run.sh
```

Если проект скачан архивом ZIP, на Linux может понадобиться дать скрипту права исполнения (`chmod +x run.sh`) или запустить через `bash run.sh`.
В Debian и Ubuntu может понадобиться пакет для виртуального окружения: `sudo apt install python3-venv`.

### После запуска

Браузер откроется сам на **http://localhost:8000** (карте требуется доступ в интернет для загрузки подложки OpenStreetMap). Если не открылся, перейдите по адресу из консоли.
Когда порт 8000 занят, скрипт берёт следующий свободный. Свой порт: `.\run.bat 8088` или `./run.sh 8088`.
Остановить сервер: Ctrl+C.

### Docker (вместо Python)

```bash
docker compose up --build
```

Затем откройте http://localhost:8000.

## Как пользоваться

1. Сразу открывается участок «Восток»: заявки на карте, бригады и заявки в списке слева. Другой участок
   выбирается в меню с его названием слева вверху.
2. **Рассчитать план** (справа вверху): маршруты на карте, расписание бригад внизу, показатели сверху.
3. Щёлкните заявку на карте или в списке. Справа будет видно, почему её взяла эта бригада и кто ещё
   мог бы.
4. **Событие дня**: авария, новая заявка, отмена или сход бригады. План перестроится, а панель
   «Что изменилось» покажет разницу.
5. **Сравнение с базовым** (переключатель вверху): число бригад и пробег против базового варианта из ТЗ.

На всех трёх участках наш план назначает все заявки меньшим числом бригад и с меньшим пробегом.
Все планы проходят независимую проверку ограничений: навык, транспорт, окно клиента, смена бригады.
План считается за несколько секунд, перепланирование после события — за миллисекунды.

Бригады, смены и аварии заданы по разъяснениям экспертов 29.09: бригады и их навыки — по реальному
дню диспетчеров на тех же участках, смены 2/2 и 5/2, авария — по полю HD «Авария», соседние дома
в Кашире и Ступино — одна авария на узле. Подробности — в [документации](docs/DOCUMENTATION.md#7-данные).

Качество проверено на 100 сценариях разных видов (город, пригород, пики, аварии, дефицит навыков,
перегрузка, 300 заявок) с днём событий и против эталона OR-Tools: нарушений нет, базовый вариант
хуже в 99 сценариях из 100, бригад не больше, чем у эталона. Подробности — в разделе
[«Проверка качества»](docs/DOCUMENTATION.md#проверка-качества).

## Состав репозитория

```

datasets/    данные трёх участков (JSON)
docs/        документация
```

Схема решения, алгоритм, метрики, ограничения, данные и допущения описаны в
[docs/DOCUMENTATION.md](docs/DOCUMENTATION.md).

## Для разработчиков

```bash
cd backend
.venv/bin/python -m pip install -e ".[dev]"   # в Windows: .venv\Scripts\python
.venv/bin/python -m pytest -q                 # тесты
.venv/bin/python -m app.cli benchmark         # наш план против базового по трём участкам
.venv/bin/python -m app.bench --quick         # стенд качества: синтетические сценарии разных видов
cd ../frontend
npm ci && npm run dev                         # интерфейс с горячей перезагрузкой: http://localhost:5173
```

Окружение `backend/.venv` создаёт скрипт запуска. Для интерфейса нужен Node.js 20.19+.
После правок интерфейса выполните `npm run build` и закоммитьте `frontend/dist`.
